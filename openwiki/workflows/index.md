# Files

- [Context assembly and prompt engineering](context-engineering.md) - How Open SWE converts source events into durable, attributed transcripts and renders fresh system, sender, repository, workspace, and skill context for each run without rewriting prior messages.
- [Follow-up, interruption, and completion handling](follow-up-messages.md) - How follow-up work either interrupts or waits behind a durable thread run, how live-run messages are injected from the store, and how stop and completion paths clean up and notify users.
- [Inbound Invocation to Durable Run](invocation.md) - How signed GitHub, Linear, and Slack callbacks, dashboard-managed schedules, and desktop-configured runs become typed, durable LangGraph executions. It documents admission gates, deterministic thread routing, dispatch defaults, and completion handling.
- [Pull-request delivery and approval](pr-creation.md) - How Open SWE pushes a branch, creates an attributed pull request, records delivery, and handles CI, feedback, and review. It also explains the approval gate for GitHub Actions workflow changes and how approval resumes the blocked push.
- [Pull-request review and re-review](pr-review.md) - How Open SWE routes GitHub pull-request events into a durable reviewer thread, validates and publishes findings, and re-reviews watched pull requests after meaningful changes.
- [Scheduling, background work, and CI monitoring](scheduling-and-baby-sit.md) - The model-free scheduler routes cron and delayed work, while durable background monitors, thread wakeups, cost refreshes, and baby-sit watches provide bounded follow-up automation.
